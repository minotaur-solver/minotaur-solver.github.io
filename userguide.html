Minotaur User Guide

A step-by-step guide for modeling, configuring, running, and embedding the Minotaur MINLP toolkit using AMPL, Pyomo, command-line executables, and the C++ API.

1. Overview & Available Solvers

Minotaur provides distinct specialized solver engines depending on the mathematical structure of your Mixed-Integer Nonlinear Programming (MINLP) model:

mbnb (Convex MINLP Branch-and-Bound)

A nonlinear programming (NLP) based branch-and-bound solver designed for convex MINLP problems. At each node of the branch-and-bound tree, continuous NLP subproblems are solved (e.g., using FilterSQP or Ipopt).

mqg (LP/NLP Branch-and-Cut)

Implements the Quesada-Grossmann LP/NLP branch-and-cut algorithm. It constructs linear relaxations of convex MINLPs and dynamically adds linearization cuts on the fly while branching on integer variables.

mglob (Global Optimization)

A spatial branch-and-bound engine for global optimization of Nonconvex Mixed-Integer Quadratically Constrained Quadratic Programs (MIQCQP). Constructs convex quadratic relaxations and performs spatial partitioning.

mmultistart (Nonconvex Multistart)

A heuristic framework for finding high-quality feasible solutions to general nonconvex MINLPs by initiating local branch-and-bound searches from multiple generated starting points.

2. Command Line Interface

Minotaur executables read standard AMPL binary stub files (.nl format) generated by algebraic modeling languages.

Basic Command Structure

# Run mbnb on an AMPL .nl stub file
mbnb problem_name.nl

# Run mqg with custom options
mqg --log_level 3 --relative_gap 1e-5 problem_name.nl

# Run mglob for global optimization
mglob --bnb_time_limit 300.0 problem_name.nl

Passing Option Files

You can specify options in a local minotaur.opt configuration file located in your working directory:

# Contents of minotaur.opt
log_level 2
bnb_time_limit 600.0
relative_gap 1e-4
brancher rel

3. AMPL Modeling & Solver Integration

Minotaur connects directly to AMPL via the AMPL Solver Library (ASL). You can select Minotaur as your active solver and configure parameters directly within your AMPL script.

AMPL Script Example

# Declare decision variables
var x1 binary;
var x2 >= -10, <= 10;

# Define objective function
minimize Cost: x1^2 + 2 * x2^2;

# Define constraints
subject to Constraint1: x1 * x2^2 <= 2;
subject to Constraint2: 2 * x1 + x2 >= 1;

# Set Minotaur as the solver
option solver minotaur;

# Pass solver-specific parameters to Minotaur
option minotaur_options 'log_level=2 bnb_time_limit=120.0 brancher=rel';

solve;

# Display optimal solution values
display x1, x2, Cost;

4. Pyomo (Python) User Guide

Pyomo users can interface with Minotaur using the SolverFactory interface. Minotaur receives Pyomo models via temporary .nl files and returns optimal primal/dual solutions.

Python Script Example

from pyomo.environ import *
from pyomo.opt import SolverFactory

# 1. Initialize Pyomo Concrete Model
model = ConcreteModel(name="Minotaur_Pyomo_Example")

# 2. Define Variables
model.x = Var(domain=Binary, initialize=0)
model.y = Var(domain=Reals, bounds=(0, 5), initialize=1.0)

# 3. Define Objective & Constraints
model.obj = Objective(expr=model.x**2 + (model.y - 3)**2, sense=minimize)
model.con1 = Constraint(expr=model.x + model.y >= 1.5)
model.con2 = Constraint(expr=model.x * model.y <= 2.0)

# 4. Instantiate Minotaur Solver
# Specify executable name (e.g. 'mbnb', 'mqg', or 'mglob')
solver = SolverFactory("mbnb")

# 5. Set options on the solver instance
solver.options["log_level"] = 2
solver.options["relative_gap"] = 1e-4

# 6. Solve and output solver logs
results = solver.solve(model, tee=True)

# 7. Print Solution
print(f"Optimal x: {value(model.x)}")
print(f"Optimal y: {value(model.y)}")
print(f"Objective Value: {value(model.obj)}")

5. C++ API Developer Guide

Developers can embed Minotaur directly into custom C++ applications. The framework provides computational graph abstractions (Problem, Variable, Constraint, Function) and tree managers (Bnb).

C++ Program Example

#include <iostream>
#include "Environment.h"
#include "Problem.h"
#include "Bnb.h"

using namespace Minotaur;

int main(int argc, char** argv) {
    // 1. Initialize Minotaur Environment
    EnvPtr env = new Environment();
    env->getOptions()->findBool("use_native_cgraph")->setValue(true);

    // 2. Create Problem Container
    ProblemPtr problem = new Problem(env);

    // 3. Add Variables
    VariablePtr x1 = problem->newVariable(0, 1, Integer, "x1");
    VariablePtr x2 = problem->newVariable(-5.0, 5.0, Continuous, "x2");

    // 4. Create Quadratic Objective Function
    QuadraticFunctionPtr qf = new QuadraticFunction();
    qf->addTerm(x1, x1, 1.0);
    qf->addTerm(x2, x2, 1.0);
    problem->newObjective(new Function(nullptr, qf), 0.0, Minimize);

    // 5. Add Linear Constraint: x1 + x2 >= 1.0
    LinearFunctionPtr lf = new LinearFunction();
    lf->addTerm(x1, 1.0);
    lf->addTerm(x2, 1.0);
    problem->newConstraint(new Function(lf), 1.0, INFINITY);

    // 6. Solve Problem with Branch-and-Bound
    Bnb bnb(env);
    bnb.solve(problem);

    // 7. Retrieve Solution
    SolutionPtr sol = bnb.getSolution();
    if (sol) {
        std::cout << "Optimal Objective: " << sol->getObjValue() << std::endl;
    }

    return 0;
}
